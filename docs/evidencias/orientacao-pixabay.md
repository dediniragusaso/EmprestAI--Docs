# Orientação do professor: Pixabay no lugar do Pexels

- Data: 09/11/2026
- Contexto: orientação dada em sala pelo professor (Grilo), fora do enunciado escrito.
- Conteúdo: usar o Pixabay como fonte de imagens, porque o Pexels apresenta problema. As imagens devem ficar em 800x600, e o Pixabay entrega outro tamanho por padrão, então é necessária uma biblioteca de processamento de imagem para redimensionar.
- Efeito: contraria o trecho do enunciado "só a API do Pexels" e a exigência do crédito "Fotos: Pexels". A skill imagens-equipamentos passa a usar o Pixabay.
- Registro: sem mensagem escrita; orientação verbal.
